Styling components with JIT CSS-in-JS.

Style

Creates or retrieves a CSS stylesheet entry with the given class name and style definition. Can be called with or without the new keyword. The style is immediately registered in a <style> element and available for use. CSS property names are converted from camelCase to kebab-case. Custom variables are prefixed with $ in the definition and become -- in CSS.
const cardStyle = Style.Class("card", { backgroundColor: "#fff", borderRadius: "8px" });
// className: "card", renders: .card { background-color: #fff; border-radius: 8px }
